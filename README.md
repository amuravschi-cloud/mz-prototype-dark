# Metalica Zuev — прототип сайта, тёмная версия

Тёмный первый экран с интерактивной 3D-композицией металлопроката (Three.js), дальше чередование тёмных и светлых блоков, акцент — оранжевый.
Номенклатура показана картинками с подписями; картинки рендерятся в браузере тем же 3D-металлом (`metal-hero.js` → `renderProductThumbs`).

Тексты, данные каталога и логика (калькулятор, справочник весов, базы, заявка) взяты без изменений из [mz-prototype](https://github.com/amuravschi-cloud/mz-prototype).

- `index.html` — собранная страница (генерируется, руками не править)
- `metal-hero.js` — 3D-герой и рендер картинок номенклатуры
- `src/style.css` — стили; `src/build.py` — сборка из исходного прототипа (`../mz-prototype-src/index.html`)
